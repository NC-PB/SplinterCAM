# AQ-055: The setup sheet's format, file and language (plan 0009)

- Asked: 2026-11-08, plan 0009 step 1 (SPEC draft, lane S), by the coding agent (headless run)
- Box: 1 (Peter's judgement: what the operator gets in hand; a new dependency would need an ADR)
- Question: In what form does the operator get the sheet? The feature map (Project Spike `product/feature-map.md`, section 8, Peter 2026-10-03) agrees "HTML and PDF in the interface language, from a template in the shop folder"; Q-137 item 5 (open) recommends templates later and a fixed sheet in release 1. For the slice:
  - (a) **HTML**, one self-contained file `<program name>.setup.html` next to the NC program (e.g. `RECT_FILLETS.setup.html` beside `RECT_FILLETS.h`), fixed layout, no picture, no template. Opens in any browser on the shop PC and prints on A4 from there. No new dependency (Python's standard library escapes the text). PDF later, from the same values.
  - (b) **Plain text** `<program name>.setup.txt`: opens anywhere, also in the control's editor if it is copied there; but tables of tools and points line up only in a fixed-width font, and it is not one of the feature map's two formats.
  - (c) **PDF** now: what most shops print; needs a PDF library, so an ADR and a dependency decision first, and a test of the PDF's text.
  Language: the feature map says the sheet follows the interface language, German being the first translation in release 1. The interface's translation system (Qt, `apps/desktop`) does not exist yet and the sheet is written outside Qt. Options: (i) English only in the slice, German with the translation work; (ii) German now as a fixed second text set (every sentence twice, no translation tooling).
- Recommendation: (a) and (i). HTML is one of the agreed formats, costs no dependency and prints; the values are computed separately from the layout (DEC-SHT-001), so PDF, templates and German replace only the renderer later. Safe default taken: (a) and (i) in the SPEC draft (`src/splintercam/setupsheet/SPEC.md`, REQ-SHT-018); nothing is coded before the answer.
