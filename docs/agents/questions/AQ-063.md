# AQ-063: A skipped entity on the pocket's layer stops the import (plan 0008, step 2)

- Asked: 2026-11-08, plan 0008 step 2 (SPEC draft, lane IO, after the spec review), by the coding agent (headless run)
- Box: 1 (Peter's judgement: what is refused, and the risk of cutting the wrong part)
- Question: io skips entities it does not read and goes on. That covers SPLINE, ELLIPSE, INSERT (blocks), HATCH, 3D and spline-fit polylines (`DXF_SKIPPED`, info), and also entities at another z or with an invalid value (`DXF_NOT_PLANAR`, `DXF_ENTITY_INVALID`, warnings). For the profile this is safe. A skipped piece of the outline leaves an open chain, and the import stops (REQ-IO-026). For a pocket it is not safe. An island drawn as one closed SPLINE or ELLIPSE, inserted as a block, or drawn 0.1 mm above the others is skipped whole. The region then has one loop fewer, and the pocket mills straight through the island: the part loses material the drawing keeps and is scrap. What should happen?
  - (a) **Refuse.** Any skipped entity on the selected layer (the whole drawing when no layer is named) that could be a wall stops the import with `DXF_REGION_INCOMPLETE` (error) per entity, naming its index, type and handle. Only annotation is let through, with its info as today: TEXT, MTEXT, DIMENSION, LEADER, MULTILEADER, TOLERANCE, POINT. On the machine nothing is cut until the drawing is fixed (the spline exploded into arcs, the block exploded, the z corrected) or the pocket is put on its own layer. Cost: a drawing with a SPLINE logo in its title block and no layer named is refused; naming the layer solves it.
  - (b) **Warn.** The import goes on, with a warning per skipped entity; the user must notice it, and the loop count of `DXF_PART_SIZE` ("1 loop" where 2 were drawn). This is the profile's rule, but it can produce the wrong part without any error.
  - (c) **Refuse only skips inside the outer loop**: needs the loop tree in io and a box test for each skipped entity; more code, and a skipped entity's extent is not always known (a block).
- Recommendation: (a). It is the conservative choice and costs about 10 lines: no program is written from a drawing io could not read in full. Safe default taken: (a), as REQ-IO-036 (Draft, provisional) in `src/splintercam/io/SPEC.md` and DEC-IO-006 (6) in `src/splintercam/io/DECISIONS.md`.
